# Meta Back-End Developer Capstone — Little Lemon

Implements Django-served restaurant pages, MySQL configuration, menu CRUD with
DRF, authenticated booking CRUD endpoints, registration/JWT authentication,
duplicate-booking prevention, and Django tests.

Follow `Readme.txt` for reviewer endpoints, JSON examples, and setup.
The backing MySQL database is local; reviewers must configure their own
credentials and create the database before migration.
This ZIP is a prepared project, not a deployed service or a GitHub repository.
